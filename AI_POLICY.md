# AI Policy

We permit the use of AI, i.e. LLMs, to support contributions. However, contributors are
solely responsible for any code they submit, and maintainers are responsible for any
code that is merged and released. All contributions are expected to meet high quality
standards and be scoped to be reviewable by a human.

Contributors must write comments themselves when communicating with maintainers.
AI-generated comments, including issue comments, pull request comments, and responses to
review feedback, are not permitted. Comments that appear to be generated by AI may be
hidden at the maintainers' discretion.

When opening an issue, contributors must describe the topic in their own words, reflect
the contributor's own understanding of the topic and its impact.

When opening a pull request, contributors must be able to explain the proposed changes
in their own words. This requirement applies to the pull request description and to all
follow-up responses during review. Contributors must not copy AI-generated responses
when replying to maintainers or others participating in the discussion.

When opening a security advisory draft, contributors must write the content in their own
words and must understand the subject matter, affected behavior, and potential impact.
This requirement applies to the security advisory description and to all follow-up
responses during triage. Contributors must not copy AI-generated responses when replying
to maintainers or collaborators in the discussion.

All AI-assisted work must involve a human contributor who understands the generated
output and takes responsibility for it. Autonomous agents must not be used to create or
submit contributions to this project. Pull requests that appear to have been created
autonomously may be closed at the maintainers' discretion.

If a contributor wishes to include material from an interaction with an AI system in a
comment, that material must be clearly identified as AI-generated, appear in a
[quote block] (i.e., `>`) or [collapsed section], and be accompanied by human-written
commentary explaining its relevance and implications. Contributors should avoid
including lengthy excerpts from AI outputs.

We recognize that AI tools may be helpful for contributors who are not native English
speakers. Contributors may use AI to improve clarity or grammar, provided the final text
reflects their own meaning, judgment, and voice. When using AI for translation,
contributors are encouraged to draft in their native language and include the
AI-translated text in a [quote block].

[collapsed section]: https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/organizing-information-with-collapsed-sections
[quote block]: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#quoting-text
